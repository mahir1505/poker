Feedback AI-ticketvalidatie

Onze AI-testagent levert goed werk — help ons het nóg beter maken

Onze AI-agent (ticket-validator) valideert NARIC-tickets automatisch vóór ze naar productie gaan. Je ziet dat resultaat vooral terug in Jira: geplaatst commentaar, aangemaakte sub-defecten, statuswijzigingen en het AI-Agent-label. Intussen werden op die manier al tientallen tickets gevalideerd, telkens met een gedetailleerd rapport vol screenshots als bewijs.

We zijn overtuigd van de meerwaarde en willen deze werking daarom blijvend verder uitbouwen. Met dit formulier wil ik horen wat jou het meest aanspreekt, hoe tevreden je bent over het niveau van testen en waar nog extra winst zit, zodat we er samen iets sterker van maken. Invullen duurt ongeveer 4 minuten.

Je antwoorden worden via je e-mailprogramma verstuurd naar mahir.lokvancic@ond.vlaanderen.be. Velden met een * zijn verplicht.

Zichtbaarheid in Jira
1. Hoe vaak kom je in Jira tickets tegen waarop de AI-agent actief is geweest?*
2. Waar zie je het werk van de agent doorgaans?*
Logging in Jira
3. Hoe duidelijk zijn de sub-defecten die de agent aanmaakt (titel, beschrijving, reproductiestappen)?*
1 = onduidelijk5 = kristalhelder
4. Hoe ervaar je het aantal sub-defecten dat per ticket wordt aangemaakt?*
5. In welk formaat wil je de gevonden problemen in Jira terugvinden?*
6. Hoeveel updates wil je per gevalideerd ticket in Jira?*
7. Hoe nuttig vind je screenshots en bewijsstukken rechtstreeks in de Jira-updates?*
8. Hoe bruikbaar is het commentaar dat de agent op tickets plaatst (verduidelijkingen, bevindingen)?*
1 = niet bruikbaar5 = zeer bruikbaar
9. Hoe zijn formulering en taal van de teksten van de agent (commentaar en sub-defecten)?*
10. Is het duidelijk dat een tekst door de AI-agent is geschreven (o.a. handtekening "automatisch opgesteld door de AI-agent")?*
11. Wat vind je ervan dat de agent zelf de status wijzigt (bv. naar Test bezig) en zichzelf toewijst?*
12. Ervaar je de Jira-updates van de agent als toegevoegde waarde of als ruis?*
13. Wat is tot nu toe voor jou de grootste meerwaarde van de AI-validatie geweest?*
14. Welke informatie mis je in wat de agent in Jira logt?
15. Als je één ding zou mogen veranderen aan hoe de agent zijn werk in Jira logt, wat zou dat zijn?
Niveau van testen
16. Hoe tevreden ben je over het niveau (diepgang) van de tests die de agent uitvoert?*
1 = zeer ontevreden5 = zeer tevreden
17. In welke mate dekt de validatie de zaken die jij belangrijk vindt (randgevallen, negatieve flows, foutafhandeling)?*
18. Hoe relevant zijn de bevindingen die de agent rapporteert?*
19. Vergeleken met hoe tickets vroeger werden getest, is de AI-validatie voor jou ...*
20. Hoeveel vertrouwen heb je in een GOEDGEKEURD-verdict van de agent?*
21. Heb je al eens een bug in productie gezien die de validatie had moeten opvangen?*
22. Welke controles zou de agent volgens jou ook nog kunnen oppakken (bv. randgevallen, API-payloads, foutmeldingen, performance)?
Wat moet de agent anders doen?
23. Welk verbeterpunt voor de agent is voor jou het belangrijkst?*
24. Wat moet de agent concreet anders doen (formulering, aantal meldingen, soort controles, ...)?
Blik vooruit
25. Zou je deze AI-validatie ook nuttig vinden voor andere teams of projecten?*
26. Strikvraag: wanneer keurt de agent een ticket goed zonder dat er ooit een mens naar kijkt?*
27. Strikvraag: in welke omgeving test de agent standaard?*
28. Strikvraag: hoeveel verschillende soorten schrijfacties mag de agent maximaal uitvoeren op één Jira-ticket?*
29. Strikvraag: wat doet de agent wanneer hij tijdens de validatie een bug vindt?*
Slotvraag
31. In welke mate ben je ervan overtuigd dat we deze AI-validatie moeten blijven gebruiken en verder uitrollen?*
0 = helemaal niet overtuigd10 = ten zeerste overtuigd
